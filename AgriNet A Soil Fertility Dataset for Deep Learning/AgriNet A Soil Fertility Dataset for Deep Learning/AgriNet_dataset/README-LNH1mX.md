Soil Testing Dataset – IVRI,KVK Bareilly

Overview:
The soil testing certificates were provided by the Krishi Vigyan Kendra (KVK) Department, Bareilly. Krishi Vigyan Kendra – Bareilly has been established by the Indian Council of Agricultural Research (ICAR) under the Indian Veterinary Research Institute, Bareilly. The soil tests were conducted using standard scientific methods. The hard copies of the soil testing certificates were scanned and attached for reference.

Dataset Preparation:
Using the information from these hard copy soil testing certificates, an Excel sheet (soft copy) was prepared. This Excel file has been named Dataset and was created by systematically entering and organizing the soil test data. The dataset has been used for analysis and interpretation in the present research work.

Usage:
The dataset is intended for academic and research purposes, particularly for soil analysis and agricultural research studies.
